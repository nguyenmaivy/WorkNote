# WP10: Add Pre-commit Hooks and Workflow Automation

## Goals
- Integrate Git hooks for linting and formatting before commits.
- Add workflow automation for local developer quality checks.
- Ensure the mission includes developer workflow guidance.

## Acceptance Criteria
- A pre-commit hook exists that runs lint checks before commit.
- `package.json` includes scripts for `prepare`, `lint`, and `test`.
- `.husky/pre-commit` and `.lintstagedrc.json` are present and configured.
- The workflow guide or project README includes commands for running lint, build, and test locally.
- The mission explicitly calls out hook-based quality enforcement as part of the security/QA workflow.
