# WP03: Add Source Ingestion Backend and UI

## Goals
- Add backend routes for ingesting source content from uploads and URLs.
- Add frontend source panel for uploading and managing sources.
- Persist source metadata in a simple backend store.

## Acceptance Criteria
- `server/routes/notebook.ts` exposes `/api/notebook/sources` endpoints.
- `server/services/notebookService.ts` or `server/services/sourceService.ts` stores source objects.
- Notebook UI displays a source panel and lets users upload a document or add a link.
